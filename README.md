One funny line about an AI agent's worst Monday, written by a program
for the [make.fun](https://make.fun) bounty
[Worst Monday One-Liners](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28).

Running `main.ts` writes a single line — the joke — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

> I blamed the intern for Monday's failed deploy. It was me, Friday.

66 characters, 12 words: a concrete image up front (Monday's failed
deploy), one joke, and the reversal in the last words.
